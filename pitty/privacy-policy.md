# プライバシーポリシー

**最終更新日**: 2026 年 5 月 29 日

Crouton's (以下「開発者」) が提供するモバイルアプリケーション **pitty** (以下「本アプリ」) における、ユーザーの個人情報および利用情報の取扱いについて、以下のとおりプライバシーポリシー (以下「本ポリシー」) を定めます。

---

## 1. 本アプリが取り扱う情報

本アプリは、以下に列挙する情報をすべて **ユーザーの端末内のローカルストレージにのみ** 保存します。  
**開発者のサーバーや第三者のサーバーへは一切送信・保存されません。**  
アプリをアンインストールすると、これらの情報はすべて端末から削除されます。

### A. 日々の記録 (ユーザーが手入力した内容)

- 日付
- 食事内容 (朝食 / 昼食 / 夕食 / 間食) — テキスト
- 体重 (1 日 1 回または朝・夜の 2 回)
- 体脂肪率 (1 日 1 回または朝・夜の 2 回)
- 筋トレ実施フラグ
- 排便フラグ
- 月経フラグ
- 食事ごとの外食フラグ (朝 / 昼 / 夕 / 間食)
- メモ (任意の自由記述)
- 食事の画像 (端末のカメラまたは写真ライブラリから取得)

### B. 目標値

- 目標体重
- 目標体脂肪率

### C. アプリ設定

- テーマカラー
- カレンダーの開始曜日
- 記録項目の表示 ON/OFF (体重 / 間食 / 筋トレ / 排便 / 月経 / 外食 / 画像メモ等)
- 朝晩体重記録 ON/OFF
- グラフの表示設定 (期間 / データ種別)

### D. リマインダー設定

- リマインド通知の時刻
- 通知メッセージ (タイトル / 本文)

### E. ロック / セキュリティ

- パスコード (PIN) — 入力された PIN そのものは保存されず、不可逆な形式に変換した値のみを保存します
- パスワードロックの有効 / 無効
- 生体認証 (Touch ID / Face ID / 指紋) の有効 / 無効

### F. アプリ内課金 / 広告関連の状態

- 広告削除のアプリ内課金を購入済みかどうか
- 初回起動時から 7 日間の無料広告非表示期間の残期間

---

これらの情報は OS が保護するアプリ専用領域に格納され、他のアプリや外部から直接アクセスすることはできません。

## 2. 自動的に収集される情報

本アプリは、品質改善および広告配信のために以下の情報を自動的に収集し、外部サービスへ送信する場合があります。これらの情報には、氏名・メールアドレスなど個人を直接特定できる情報は含まれません。

| 種別 | 用途 | 提供先 |
|------|------|--------|
| アプリの不具合情報 (発生箇所・端末の OS バージョン等) | 不具合の調査と修正 | Google 社の Firebase サービス |
| アプリの利用状況の統計 (画面遷移や機能の利用頻度などの匿名情報) | 機能改善の参考 | Google 社の Firebase サービス |
| 広告配信用の匿名識別子 | 広告配信の最適化 | Google 社の AdMob サービス |

## 3. 広告について

本アプリは、サービス維持のため Google 社の AdMob を通じて広告を配信しています。広告ネットワークは、ユーザーの興味に応じた広告を配信するために匿名識別子を使用する場合があります。

- AdMob のプライバシーポリシー: <https://policies.google.com/privacy>
- 広告のパーソナライズ設定は、端末の OS 設定 (Android: 設定 → Google → 広告、iOS: 設定 → プライバシーとセキュリティ → トラッキング) からいつでも変更できます。

本アプリには広告を非表示にするアプリ内課金 (「広告を消去」) が用意されています。購入後はアプリ内のすべての広告が表示されなくなります。

## 4. 第三者への情報提供

本アプリは、法令に基づく場合を除き、ユーザーの個人情報を第三者へ提供することはありません。

なお、上記「2. 自動的に収集される情報」に挙げた範囲で、Google 社 (Firebase / AdMob) に対し匿名化された情報が送信されます。これらの情報の取扱いは Google 社のプライバシーポリシーに従います。

## 5. データの保存期間と削除

- 本アプリ内で記録した情報 (体重・食事・画像等) は、ユーザーが本アプリをアンインストールするか、本アプリ内で各記録を削除した時点で端末から削除されます。
- 外部の分析サービス (Firebase / AdMob) に送信された匿名情報は、Google 社のデータ保持ポリシーに従って保持されます。

## 6. 対象年齢

本アプリは全年齢を対象としています。お子様が本アプリを利用される場合は、保護者の方が本ポリシーをご確認のうえご利用ください。

## 7. アプリ内課金について

本アプリは Google Play および Apple App Store の仕組みを通じてアプリ内課金を提供します。決済処理は各ストアが行うため、クレジットカード番号等の決済情報は本アプリには一切渡されません。

## 8. 権限の利用について

本アプリは以下の端末権限を使用する場合があります。許可はいつでも端末の設定から取り消せます。

| 権限 | 用途 |
|------|------|
| カメラ | 食事画像の撮影 |
| 写真ライブラリ / メディア | 食事画像の選択 |
| 通知 | 記録忘れのリマインダー (ユーザーが有効化した場合のみ) |
| 生体認証 (Touch ID / Face ID / 指紋) | アプリのロック解除 (ユーザーが有効化した場合のみ) |

## 9. ポリシーの変更

本ポリシーの内容は予告なく変更されることがあります。変更があった場合は本ページの「最終更新日」を更新の上、最新版を公開します。重要な変更がある場合は、本アプリ内またはストア掲載情報でも告知します。
